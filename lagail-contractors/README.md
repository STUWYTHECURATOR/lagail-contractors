# Lagail Contractors Website

Static HTML5, CSS3, and JavaScript website for **Lagail Contractors** (Lusaka, Zambia) — ready for GitHub Pages or any static web host.

## Included Files
- `index.html` — Home page with hero banner, core services, and company highlights
- `about.html` — Company overview, mission, vision, and values
- `services.html` — Full list of technical & contracting services with direct quote links
- `gallery.html` — Interactive filterable project gallery with lightbox preview
- `contact.html` — Contact details, map, and instant WhatsApp enquiry form
- `css/style.css` — Responsive stylesheet
- `js/script.js` — Mobile menu, gallery filters, lightbox, and form handling
- `images/logo.jpeg` & `images/hero-bg.jpeg` — Brand logo and field installation background

## Hosting with GitHub Pages
1. Create a new repository on GitHub (e.g., `lagail-contractors`).
2. Extract this ZIP folder and push all files to your repository:
   ```bash
   git init
   git add .
   git commit -m "Initial Lagail Contractors website"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/lagail-contractors.git
   git push -u origin main
   ```
3. In GitHub, open **Settings > Pages**, select the `main` branch (`/ (root)`), and click **Save**.
4. Update the placeholder phone number (`260970000000`) in `js/script.js` and the HTML files with your live company WhatsApp number.
